    模型怎么放喵？

    Cubism 4：把整个模型文件夹放到 models/palico/，保持 palico.model3.json、.moc3、贴图、motions/ 的相对结构不变，然后把路径填进上面。

    Cubism 2：填 model.json 路径并把 SDK 切到 live2d-widget。

    浏览器直接双击打开时本地 json 会被 CORS 拦，请在本目录起个静态服务：
    python -m http.server 8080
    然后访问 http://localhost:8080。加载失败时会自动启用 SVG 替身猫，计时功能不受影响喵。

    注意：内置预览面板是带 CSP 的沙箱，会拦外部 fetch（模型 json 取不到），且不会放行工作区里新建的 models/ 目录。想验证自己的模型，请用上面的本地服务打开页面喵。
