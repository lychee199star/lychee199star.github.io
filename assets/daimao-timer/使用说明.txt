呆猫计时器 · 交付包使用说明
================================

包内文件：
  index.html                  成品页面（双击可看演示呆猫）
  提示词.md                    给 dsh 的完整规格
  预览.png                     最终效果截图
  呆猫计时器-完整资料.md       全部资料汇总（需求 + 源码 + 部署 + 排错 + 验证）

1) 只看效果：双击 index.html。演示模型走外网，断网会自动换成 SVG 替身猫。
2) 接自己的模型：
     cd 到本目录，运行  python -m http.server 8080
     浏览器打开 http://localhost:8080/index.html
     模型文件夹放到 models/palico/，保持 .moc3 / 贴图 / motions 的相对结构
     点右上角 ⚙ → 填 ./models/palico/palico.model3.json → 加载模型
3) 报「模型初始化失败」：多半是预览面板的 CSP 拦了外部请求，
   或 file:// 下填了本地路径。看 完整资料.md 第 5 节，或用 ⚙ 里的「诊断模型」。
4) 让 AI 重做：把 提示词.md（或 完整资料.md 第 3 节）整段复制给 dsh。

细节全在「呆猫计时器-完整资料.md」。
