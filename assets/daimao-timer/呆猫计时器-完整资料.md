### 2.3 功能清单

- **计时**：倒计时 / 正计时；状态机 `idle → running ⇄ paused → done`；开始 / 暂停 / 继续 / 重置 / 再来一次。
- **设时**：时 0-99、分/秒 0-59，支持直接输入、`− +` 按钮、滚轮、`↑/↓`；运行中锁定编辑。
- **精度**：`performance.now()` 锚点 + `requestAnimationFrame` 算时间差，**不用** `setInterval(fn,1000)` 累加；暂停冻结差值、恢复重算锚点，切后台回来不漂移。
- **进度**：SVG `stroke-dasharray` 圆环；倒计时 `remaining/target`，正计时 `elapsed/target`（target 为 0 时按 60 分钟）；走满变金色。
- **临结束**：最后 10 秒整卡朱红描边 + 数字脉冲。
- **结束**：Web Audio 现场合成和风三音（正弦/三角波，无外链音频）→ QUEST CLEAR 弹窗（用时 + 「済」印章 + 再来一次 / 收下）→ 呆猫播报台词。
- **台词**：每次状态变化 `say()` 同时更新舞台气泡与底部状态条，3.4 秒后收起；点猫随机回一句。
- **其它**：明暗主题、静音、Toast、桌面通知（可选）、localStorage 持久化。
- **降级**：模型加载失败自动切内联 SVG Q 版替身猫（白猫 / 三角耳 / 蓝头巾 / 金铃铛，呼吸 + 眨眼），**计时功能完全不受影响**。

## 3. 计时功能规格（重点，逐条实现）

1. 两种模式：`countdown` 倒计时、`stopwatch` 正计时，切换时重置为设定时长 / 归零。
2. 可设定时、分、秒；输入即实时预览到主显示；运行中输入锁定（禁用编辑），暂停/空闲可编辑。
3. 状态机：`idle → running ⇄ paused → done`，另可随时 `reset` 回 idle。
4. **精度**：不要用 `setInterval` 累加秒数。用 `performance.now()` 记录 `endAt`（倒计时）或 `startAt`（正计时），`requestAnimationFrame` 里由时间差计算剩余/已用；暂停时冻结差值，恢复时重算锚点。页面切到后台再回来必须仍然准确。
5. 圆环进度：倒计时 = `remaining / target`；正计时 = `elapsed / target`（target 为设定时长，为 0 时按 60 分钟计），走满变金色并有轻微脉冲。
6. 主显示 `HH:MM:SS`，另外用小字显示百分秒 `.cc`；倒计时最后 10 秒整卡变朱红描边 + 数字脉冲。
7. 结束行为：状态 `done` → 合成一段和风三音提示音（Web Audio 正弦/三角波，可静音） → 弹出 QUEST CLEAR 卡片（含用时、印章「済」、「再来一次」「收下」按钮） → 呆猫播报台词 → 桌面通知可选（需用户授权，非必需）。
8. 快捷键：`Space` 开始/暂停（焦点在输入框时不触发）、`R` 重置、`1/2` 切模式、`M` 静音、`↑/↓` 微调当前聚焦的时间字段。
9. 持久化：模式、设定时长、主题、静音、模型路径存 localStorage；刷新后恢复设定值（不自动恢复运行中的计时）。
10. 每个状态变化都要调用 `say(text)`：既更新页面状态条，也调用 Live2D 实例的 `tipsMessage` 气泡（见下节）。台词示例：`任务受注喵！本喵给你看着火候～` / `暂停一下喵，喝口猫饭茶再继续～` / `继续出发喵！还差一点点！` / `任务达成喵！猫车没来，好耶！`

- 用户本地模型目录约定：`models/palico/palico.model3.json` 与 `.moc3`、纹理、`motions/` 保持原有相对结构不变。因为浏览器 `file://` 下 fetch 本地 json 会被 CORS 拦，界面要提示用户用 `python -m http.server 8080` 起本地服务后访问 `http://localhost:8080`。
- 若用户给的是 Cubism 2 的 `model.json + .moc`，改用 `live2d-widget@3.1.4` 的 `L2Dwidget.init({model:{jsonPath:...}})`；设置抽屉里给出 SDK 版本切换（cubism4 / cubism2）。
- **`models[].scale` / `models[].position` / `models[].stageStyle` 是官方参数**：`scale` 默认约 0.1（实测会显得很小，建议 0.15~0.22），`position` 默认 `[0,0]`，`stageStyle` 是作用在舞台容器上的 CSS 属性。因为用户给的每张模型尺寸都不一样，请在设置抽屉里把 **缩放** 与 **上下偏移** 做成可调数字输入并持久化，改完点「加载模型」重新生效。
- **实测坑位（务必处理）**：oh-my-live2d 默认把 `#oml2d-stage` 停靠在页面**左下角**、并额外插入 `#oml2d-statusBar` 等左侧浮层。若要让猫待在右栏舞台里，需要在检测到 `#oml2d-stage canvas` 后把 stage `appendChild` 进舞台容器，用 CSS `position:absolute !important; left:50%; bottom:0; transform:translateX(-50%); width:min(100%,360px); height:min(100%,480px)` 固定；入位前先 `opacity:0` 防止左下角闪一下；把 `[id^="oml2d-"]` 里除 stage/canvas/tips 之外的浮层 `display:none`。
- **库自带 `#oml2d-tips` 气泡在空内容时会留下一块浅蓝矩形**，建议隐藏它，改由页面自己实现台词气泡：计时状态变化时同时更新「舞台内气泡」与「底部状态条」，3.4 秒后自动收起。这样断网 / 模型 404 时台词反馈也完整。
- `#oml2d-stage { z-index: 35 !important; }` 这类覆盖仍需要；移动端隐藏桌宠但功能完整。
- **降级必做**：库脚本加载失败 / 8 秒内没有 canvas / 模型 404 时，隐藏报错，显示一个内联 SVG 绘制的 Q 版呆猫占位（白色猫、三角耳、蓝头巾、金铃铛，带呼吸与眨眼动画），并在状态条写明「模型未加载，已启用替身喵」。计时功能完全不受影响。
- **不要只看「canvas 存在」就判定成功**：实测模型路径 404 时库依然会创建 `#oml2d-stage` 和空 canvas，页面会假报「已就位」但舞台是空的。请配合一次 `fetch(模型 json)` 预检（HTTP 状态、是否合法 JSON、`Version` 字段、Moc/Textures 声明、SDK 是否匹配）或库实例的 `onLoad` 事件来判定真正就绪。
- **必须做「诊断模型」面板**：输出页面协议、模型地址、SDK、HTTP 状态、`Cubism Version`、`Moc/Texture0` 字段，以及 `window.unhandledrejection` 捕获到的库内部错误（库有 `fetch('https://unpkg.com/oh-my-live2d@latest/package.json')` 版本检查，失败会产生未捕获的 Promise 错误）。失败文案要带 `e.message`，不要只写一句「初始化失败」。
- **带 CSP 的预览沙箱会拦模型**：例如某内置预览服务器返回 `connect-src 'self' ...`（不含任意 `https:`），外部模型 json 的 `fetch` 会被直接拒绝，报 `TypeError: Failed to fetch`；同时这类服务通常只放行登记过的文件，工作区里新建的 `models/` 目录会返回 403。页面要识别这种情况并提示用户改用 `file://` 双击打开，或 `python -m http.server 8080` 自建服务验证。
- 点击呆猫时随机播报一句台词（参考站用 `stage.getBoundingClientRect()` 做命中判断 + `tipsMessage`）。

function ctx(){
  if (cfg.muted) return null;
  try {
    if (!audioCtx) audioCtx = new (window.AudioContext||window.webkitAudioContext)();
    if (audioCtx.state === 'suspended') audioCtx.resume();
    return audioCtx;
  } catch(e){ return null; }
}
function tone(freq, at, dur, type, vol){
  var c=ctx(); if(!c) return;
  var o=c.createOscillator(), g=c.createGain();
  o.type=type||'sine'; o.frequency.setValueAtTime(freq,at);
  g.gain.setValueAtTime(0.0001,at);
  g.gain.exponentialRampToValueAtTime(vol||.14,at+.02);
  g.gain.exponentialRampToValueAtTime(0.0001,at+dur);
  o.connect(g); g.connect(c.destination); o.start(at); o.stop(at+dur+.03);
}
function clickSound(){ var c=ctx(); if(c) tone(680,c.currentTime,.09,'triangle',.055); }
function chime(){
  var c=ctx(); if(!c) return;
  [523.25,659.25,783.99,1046.5].forEach(function(f,i){
    tone(f,c.currentTime+i*.17,1.05,'sine',.13);
    tone(f*2,c.currentTime+i*.17,.5,'triangle',.035);
  });
}

function inputsToCfg(){
  cfg.h = clamp(parseInt(inH.value,10),0,99);
  cfg.m = clamp(parseInt(inM.value,10),0,59);
  cfg.s = clamp(parseInt(inS.value,10),0,59);
}
function cfgToInputs(){
  inH.value=pad(cfg.h); inM.value=pad(cfg.m); inS.value=pad(cfg.s);
}
function targetMs(){ return (cfg.h*3600+cfg.m*60+cfg.s)*1000; }
function setFromMs(ms){
  var t=Math.max(0,Math.floor(ms/1000));
  cfg.h=clamp(Math.floor(t/3600),0,99); cfg.m=Math.floor((t%3600)/60); cfg.s=t%60;
  cfgToInputs();
}
function onInputChange(){
  inputsToCfg(); cfgToInputs();
  if (st.state==='idle'||st.state==='done'){
    st.target=targetMs(); st.remaining=st.target; st.elapsed=0; st.state='idle';
  }
  syncPresets(); saveStore(); render(); say(LINES.idle,true);
}
function step(unit,delta){
  if (st.state==='running') return;
  inputsToCfg();
  var max = unit==='h'?99:59;
  cfg[unit]=clamp(cfg[unit]+delta,0,max);
  cfgToInputs(); onInputChange(); clickSound();
}
['h','m','s'].forEach(function(u){
  var box=setters.querySelector('[data-unit="'+u+'"]');
  box.querySelectorAll('[data-step]').forEach(function(b){
    b.addEventListener('click',function(){ step(u,parseInt(b.dataset.step,10)); });
  });
  var input=$('in-'+u);
  input.addEventListener('input',function(){
    input.value=input.value.replace(/[^\d]/g,'').slice(0,2);
  });
  input.addEventListener('change',onInputChange);
  input.addEventListener('blur',onInputChange);
  input.addEventListener('wheel',function(e){
    if (input.disabled) return;
    e.preventDefault(); step(u, e.deltaY<0?1:-1);
  },{passive:false});
  input.addEventListener('keydown',function(e){
    if(e.key==='ArrowUp'){e.preventDefault();step(u,1);}
    if(e.key==='ArrowDown'){e.preventDefault();step(u,-1);}
    if(e.key==='Enter'){input.blur();}
  });
});
function syncPresets(){
  var t=Math.round(targetMs()/1000);
  document.querySelectorAll('.chip').forEach(function(c){
    c.classList.toggle('active', parseInt(c.dataset.sec,10)===t);
  });
}
$('presets').addEventListener('click',function(e){

});

/* ============================================================
   6. 计时核心：基于 performance.now() 锚点，不累加秒数
   ============================================================ */
function compute(){
  if (st.state!=='running') return;
  var now=performance.now();
  if (cfg.mode==='countdown') st.remaining=Math.max(0, st.target-(now-st.anchor));
  else st.elapsed=Math.max(0, now-st.anchor);
}
function start(){
  if (st.state==='done') reset(true);
  st.target=targetMs();
  if (cfg.mode==='countdown' && st.target<=0){ say(LINES.empty); toast('先设个时间喵'); return; }
  if (cfg.mode==='countdown'){
    if (st.state==='idle') st.remaining=st.target;
    st.anchor=performance.now()-(st.target-st.remaining);
  } else {
    st.anchor=performance.now()-st.elapsed;
  }
  st.state='running';
  // 区分「首次开始」「正计时开始」「暂停后继续」三种口播
  var resuming = cfg.mode==='countdown' ? (st.remaining<st.target) : (st.elapsed>0);
  say(resuming ? LINES.resume : (cfg.mode==='stopwatch' ? LINES.stopwatch : LINES.start));
  clickSound(); render();
}
function pause(){ compute(); st.state='paused'; say(LINES.pause); clickSound(); render(); }
function reset(silent){
  st.state='idle'; st.target=targetMs(); st.remaining=st.target; st.elapsed=0;
  if(!silent) say(LINES.reset); render(); saveStore();
}
function toggleMain(){
  if (st.state==='running') pause();
  else start();
}
function addMinute(){
  var before=targetMs();
  setFromMs(before+60000);
  st.target=targetMs();
  if (st.state==='running' && cfg.mode==='countdown'){
    compute(); st.remaining+=60000;
    st.anchor=performance.now()-(st.target-st.remaining);
  } else if (st.state==='idle'||st.state==='done'){
    st.state='idle'; st.remaining=st.target;
  }
  syncPresets(); saveStore(); render(); say(LINES.add); clickSound();
}
function finish(){
  st.state='done'; st.remaining=0;
  chime(); say(LINES.done);
  $('clear-duration').textContent=formatHMS(st.target,false);
  $('clear-mask').hidden=false;
  render();
}
function formatHMS(ms,withCenti){
  var total=Math.max(0,Math.ceil(ms/1000));
  var h=Math.floor(total/3600), m=Math.floor((total%3600)/60), s=total%60;
  var out=pad(h)+':'+pad(m)+':'+pad(s);
  if(withCenti){
    var cc=Math.floor((ms%1000)/10);
    return {h:pad(h),m:pad(m),s:pad(s),c:pad(cc),full:out};
  }
  return out;
}
function render(){
  compute();
  var ms = cfg.mode==='countdown' ? st.remaining : st.elapsed;
  var f = formatHMS(ms,true);
  dH.textContent=f.h; dM.textContent=f.m; dS.textContent=f.s; dC.textContent='.'+f.c;

  var ref = st.target>0 ? st.target : 3600000;
  var ratio = cfg.mode==='countdown'
    ? (st.state==='idle' ? 1 : clamp(st.remaining/ref,0,1))
    : clamp(st.elapsed/ref,0,1);
  ringFill.style.strokeDashoffset = (RING_C*(1-ratio)).toFixed(2);
  ringPct.textContent = Math.round(ratio*100)+'%';
  ringFill.classList.toggle('done', cfg.mode==='stopwatch' && ratio>=1);
  $('clock-label').textContent = cfg.mode==='countdown' ? 'REMAINING / 剩余' : 'ELAPSED / 已用';
  $('clock-sub').textContent = cfg.mode==='countdown'
    ? (st.state==='done'?'任务完成，收下喵':'目标 '+formatHMS(st.target,false))
    : (ratio>=1?'目标达成，还在继续喵':'目标 '+formatHMS(st.target,false));

  var urgent = cfg.mode==='countdown' && st.state==='running' && st.remaining>0 && st.remaining<=10000;
  board.classList.toggle('is-urgent',urgent);

  var locked = st.state==='running';
  setters.classList.toggle('locked',locked);
  [inH,inM,inS].forEach(function(i){ i.disabled=locked; });

  if (st.state==='running'){ btnText.textContent='暂停计时'; btnIco.textContent='❚❚'; btnMain.classList.add('running'); }
  else if (st.state==='paused'){ btnText.textContent='继续计时'; btnIco.textContent='▶'; btnMain.classList.remove('running'); }
  else if (st.state==='done'){ btnText.textContent='再来一次'; btnIco.textContent='↺'; btnMain.classList.remove('running'); }
  else { btnText.textContent='开始计时'; btnIco.textContent='▶'; btnMain.classList.remove('running'); }
  // 标题只在秒数或状态变化时写，避免每帧触发浏览器标签重绘
  var titleKey=st.state+'|'+Math.floor(ms/1000);
  if (titleKey!==lastTitleKey){
    lastTitleKey=titleKey;
    document.title = (st.state==='running'? f.full+' · ':'') + '呆猫计时 · PALICO TIMER';
  }
}
function tick(){
  compute();
  if (cfg.mode==='countdown' && st.state==='running' && st.remaining<=0) finish();
  render();
  requestAnimationFrame(tick);
}

function loadScript(src,key,onLoad,onErr){
  if (window[key]) { onLoad(); return; }
  var old=document.querySelector('script[data-lib="'+key+'"]');
  if (old){
    old.addEventListener('load',onLoad,{once:true});
    old.addEventListener('error',function(){
      if(old.parentNode) old.parentNode.removeChild(old); onErr();
    },{once:true});
    return;
  }
  var el=document.createElement('script');
  el.src=src; el.dataset.lib=key; el.async=true;
  el.onload=onLoad;
  // 失败时移除节点，否则备用源会被这个已失败的 script 挡住
  el.onerror=function(){ if(el.parentNode) el.parentNode.removeChild(el); onErr(); };
  document.head.appendChild(el);
}

}

function probeModel(url,manual){
  var lines=[
    '[诊断] 页面协议  '+location.protocol,
    '[诊断] 模型地址  '+url,
    '[诊断] 渲染库    '+(cfg.sdk==='widget'?'live2d-widget (Cubism 2)':'oh-my-live2d (Cubism 4)')
  ];
  if(lastLibError) lines.push('[诊断] 库内部报错  '+lastLibError);
  // file:// 下 fetch 本地 json 会被浏览器直接拒绝，不必再试
  if(location.protocol==='file:' && !/^https?:/i.test(url)){
    lines.push('[×] file:// 协议禁止读取本地 json');
    probeFatal={title:'本地模型在 file:// 下读不到',
      detail:'请在本目录运行 python -m http.server 8080，再访问 http://localhost:8080。'};
    renderProbe(lines); return Promise.resolve(lines);
  }
  return fetch(url,{cache:'no-store'}).then(function(res){
    lines.push('[诊断] HTTP 状态  '+res.status);
    if(!res.ok){
      lines.push('[×] 模型配置取不到：路径不对，或预览服务未放行该文件');
      probeFatal={title:'模型文件 HTTP '+res.status,
        detail:'检查文件名与相对路径；若用内置预览面板打开，工作区里的 models/ 目录不会被放行，请改用本地 http 服务。'};
      return lines;
    }
    return res.text().then(function(txt){
      var j;
      try{ j=JSON.parse(txt); }catch(e){
        lines.push('[×] 返回内容不是合法 JSON');
        probeFatal={title:'模型配置不是合法 JSON',
          detail:'请确认填的是 *.model3.json 或 model.json 本身，而不是文件夹或 .moc3。'};
        return lines;
      }
      var v=j.Version, refs=j.FileReferences||j;
      var moc=refs.Moc||refs.moc||j.model||'';
      var tex=(refs.Textures||refs.textures||j.textures||[])[0]||'';
      lines.push('[诊断] Cubism Version  '+(v===undefined?'无（Cubism 2 风格）':v));
      lines.push('[诊断] Moc  '+(moc||'未声明')+'    Texture0  '+(tex||'未声明'));
      var isV4=(v===3)||/\.moc3/i.test(String(moc));
      if(cfg.sdk==='widget' && isV4){
        lines.push('[×] Cubism 4 模型配了只支持 Cubism 2 的 live2d-widget');
        probeFatal={title:'模型与 SDK 版本不匹配',
          detail:'*.model3.json / *.moc3 属于 Cubism 4，请把 SDK 切回 oh-my-live2d。'};
      } else if(!moc && !tex){
        lines.push('[×] 配置里没有 Moc / Textures 字段');
        probeFatal={title:'模型配置结构损坏',
          detail:'json 里缺少模型与贴图声明，或填错了文件。'};
      } else {
        lines.push('[√] 配置可读；.moc3、贴图、motions/ 需与 json 保持原有相对目录');
      }
      return lines;
    });
  }).catch(function(e){
    lines.push('[×] fetch 失败：'+((e&&e.message)?e.message:e));
    lines.push('[提示] 常见于网络不通、跨域未开 CORS，或内置预览面板的 CSP connect-src 拦截外部请求');
    probeFatal={title:'取不到模型配置',
      detail:'网络 / CORS / CSP 拦截。内置预览面板会拦外部 fetch，请用本地 http 服务或双击 file:// 打开页面。'};
    return lines;
  }).then(function(result){
    renderProbe(result);
    if(!manual && probeFatal) showProbeFailure();
    return result;
  });
}
function watchModel(){
  var tries=0;
  var timer=setInterval(function(){
    tries++;
    var ok=document.querySelector('#oml2d-stage canvas, #live2d-widget canvas');
    if(ok){
      clearInterval(timer);
      var docked=dockStage();
      if(!docked){ showPlaceholder(true,'舞台定位失败，已启用替身喵'); return; }
      // 只看到 canvas 不等于模型加载成功（404 时库仍会建一个空舞台）
      if(probeFatal){ showProbeFailure(); return; }
      live2dReady=true;
      showPlaceholder(false,'ฅ 呆猫已就位 · 点一下戳戳它');
      say('本喵来啦喵～老大今天也要专注哦！');
    } else if(tries>24){
      clearInterval(timer);
      if(probeFatal) showProbeFailure();
      else showPlaceholder(true,'模型未加载，已启用替身喵（点 ⚙ → 诊断模型 查原因）');
    }
  },400);
}
function mountModel(){
  cleanupStage();

## 5. 模型接入 与「模型初始化失败」完整排查

### 5.1 最常遇到的那个错，实测根因

在**内置预览面板**里打开时报「模型初始化失败」，**不是模型坏了、也不是代码坏了，是打开方式把网络请求拦了**。用无头浏览器抓控制台得到的实锤：

- 预览面板走 `http://127.0.0.1:54585/...` 沙箱服务，响应头带严格 CSP：`connect-src 'self' ...` **不含任意 `https:`** → 外部 `model3.json` 的 `fetch` 被拒，报 `Fetch API cannot load ... Refused to connect because it violates the document's Content Security Policy`，最终变成 `TypeError: Failed to fetch`。
- 库内部还会 `fetch('https://unpkg.com/oh-my-live2d@latest/package.json')` 做版本检查，同样被拦，并抛出未捕获的 Promise 错误（需要 `unhandledrejection` 捕获才能看到）。
- 该服务只放行登记过的文件：工作区里新建的 `models/palico/...` 返回 **403**，所以改成填本地路径也取不到。
- 连霞鹜文楷的字体 CSS 也被 `default-src` 拦（只是字体降级，不影响功能）。

**同一份 `index.html` 用 `file://` 双击打开时演示呆猫正常**，这就是判断依据。

### 5.2 另外 5 种也会报这个错

1. 双击 `file://` 打开却填了本地相对路径 —— 浏览器禁止 `file://` 读本地 json。
2. Cubism 4 的 `model3.json/.moc3` 配了只支持 Cubism 2 的 live2d-widget（或反过来）—— 在 ⚙ 里切 SDK。
3. 模型目录被拆散：`.moc3`、贴图、`motions/`、`*.exp3.json` 必须和 json 保持原有相对结构。
4. 路径填成了文件夹或 `.moc3`，而不是 `*.model3.json` / `model.json`。
5. 两个渲染库 CDN 都不可达，或模型服务器没开 CORS。

### 5.3 打开方式对照表

| 打开方式 | 演示模型（外网） | 本地模型 | 结论 |
| --- | --- | --- | --- |
| 内置预览面板 `http://127.0.0.1:54585` | ✗ CSP 拦截 | ✗ 403 | **只适合看版式，不适合验模型** |
| 双击 `file://.../index.html` | ✓ 正常 | ✗ CORS 拦截 | 看演示呆猫用这个 |
| `python -m http.server 8080` → `localhost:8080` | ✓ 正常 | ✓ 正常 | **验自己的模型用这个** |

### 5.4 「🔍 诊断模型」按钮会输出什么

⚙ 抽屉里点它，逐项列出：页面协议、模型地址、SDK、HTTP 状态、JSON 合法性、`Cubism Version`、`Moc` / `Texture0` 字段、SDK 是否匹配、`fetch` 具体错误、以及 `unhandledrejection` 捕获到的库内部错误。失败文案带 `e.message`，不再只说一句「初始化失败」。

### 5.5 模型目录约定

```
models/palico/
  palico.model3.json      ← ⚙ 里填这个（Cubism 4）
  palico.moc3
  palico.2048/texture_00.png
  motions/*.motion3.json
  *.exp3.json
```
Cubism 2 则是 `model.json + .moc`，把 SDK 切到 `live2d-widget 3.1.4`。不同模型尺寸差异大，⚙ 里可调**缩放**（建议 0.15~0.22）与**上下偏移**。
