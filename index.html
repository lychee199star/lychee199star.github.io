FIELD NOTE 01 把复杂的事
讲清楚
2026.10.08学习8 分钟阅读

做一个让自己愿意反复打开的学习系统

工具的意义不在于把一切变得自动，而是帮我们把注意力还给真正重要的事情。这是我重新整理知识库之后的一些想法。

呃呃但整理到第三天，我有点想放弃了。

原因很简单：我本来想搭一个“让自己愿意反复打开的学习系统”，结果打开笔记软件的第一件事是数收藏夹——两百多条“稍后再看”，最早的一条躺在那里快两月了。我把笔记在三个软件之间搬来搬去，标签体系推翻重设计了四版，最后发现一个尴尬的事实：我折腾工具的热情，远远大于我学习的热情。这不叫知识管理，这叫给拖延找一个高级的形状。

更过分的是，整理着整理着，大脑开始自动生产脑洞，一个比一个离谱：

校园食堂“今天吃什么”大转盘。是啊吃什么。每天中午在食堂门口站着纠结三分钟（嘻嘻其实是被挤得走不动路。）的人，绝对不止我一个。做一个转盘小程序，把一二三餐的所有窗口全录进去，转一下，转到啥吃啥。但是问学长说这为什么没人做，说是得自掏腰包，，emmmm,是个问题。而且没有具体的窗口统计还得自己调研，甚至还有没做好店就跑（倒）路（闭）的风险......干脆加入实时更新和评论的功能好了。或许用到的：微信小程序（WXML + JS），或者干脆做网页版，CSS transform 加 JS 随机角度就能转起来；参考 GitHub 上一堆“今晚吃什么”开源项目，Wheel of Names 的逻辑也能抄。

还有一个，呆猫 mod。呆猫...呆猫...让呆猫住进各个游戏里——在 Minecraft 里跟着我挖矿，在种田游戏里蹲在田埂上看我浇水。呆猫暴君！跟我回来玩怪猎.jpg（bushi）或许用到的：Minecraft 的话是 Java + Fabric，建模用 Blockbench 一个方块一个方块拼出呆猫的脸；想先省事的话，从 Wallpaper Engine 动态壁纸做起。参考：Fabric 官方文档、CurseForge 上现成 mod 的文件结构。

对了阅读小插件。一个浏览器扩展，划词就收进知识库，顺便管稍后读和阅读进度——正好治我那两百条收藏。或许用到的：Chrome 扩展（Manifest V3），本质还是我最熟的 HTML/CSS/JS；参考 Chrome 开发者文档，功能思路抄 Cubox 和 Readwise。

最重要的！自己喜欢的 CP 的网站。家产,,,,我会孝你们一辈子的.....放时间线、语录、图集整理，给它一个自己的小花园。或许用到的：Hexo 或 Hugo 静态站加 GitHub Pages，和博客同款技术，零成本上线；注意图源版权，自用收藏就好。

四个脑洞列完，结论只有三个字：好难……每一个都好玩，每一个都要命。开头还一本正经地说要把注意力还给重要的事情，结果注意力第一个跑去做脑洞打工了。学习系统还没建出第一页，脑洞先排出了两个学期的工期。

而且话说回来，我哪来的时间做这些？课表排得满满当当，白天一头扎进教室，这几天晚上还要赶学生会面试、处理班委的事，周末被各种通知切成碎片。好充实的大学生活——充实到我某天晚上走在回宿舍的路上突然停下来想：这是高四吗？这是高四吧。。。

高四倒也不全是坏事。至少这段忙乱确认了一件事：让我愿意反复打开的，从来不是哪个软件、哪个系统，而是这些让人眼睛发亮的瞎折腾本身。学习系统慢慢搭，脑洞一个个来，都乖乖排在课表后面就好。

学费没白交——它买的其实不是课本，是确认“我喜欢什么”的这几年。好了，写完了，睡了，明天早八。

最后一科交卷的那一刻没有电影里的烟花，只有走出考场时突然变宽的天空。接下来要去哪里，终于可以自己慢慢想了。

想了什么呢？想的东西特别杂，从考场空调的风力到食堂的糖醋里脊，乱七八糟挤了一脑子，索性趁热全倒出来。

比如现在想起数学，还是有点想笑。考完那天网上都在喊“喜提大专”，我盯着最后一道大题，两页草稿写得密密麻麻，最后一问还是蒙的。背了三年的二级结论，一张都没轮上用场——以前是我们套路题，今年是题套路我们。再往前一天，语文作文让我写“词语之变”，我脑子里飞快过了一遍“内卷”“上岸”“破防”，随便挑一个都是现成的八百字，最后挑了个最安全的，写得四平八稳。交卷铃响我才想起来，我最想写的词根本没敢落笔：“累”。出分之前谁先喊累，谁就像在给自己找退路，这个道理我练了三年。

考完化学那晚躺在床上看书，听拿着手机的舍友吐槽说，热搜全是哀嚎，官方还一本正经地说今年难度保持稳定——稳定，大概指的就是稳定地让人破防。物理就更别提了，写完最后一道大题手腕是麻的，网上说今年物理“奔着选拔物理学家去的”，我举双手赞成：我只想当个普通考生，突然被按物理学家的标准培养，压力很大的好不好。最气的是地理，作为我的最后一科，全网都说它简单，我却在某道选择题上纠结了五分钟，改了又改。这就是物化地考生的命：被吐槽的科目一门不落，被夸简单的科目也没放过我。

说起来，在山东，“摆烂”这个词是没有生存土壤的。嘴上摆烂的人，手上都在估分；嘴上“完了完了”的人，转头就在对答案。六点的闹钟、十点半的晚自习、课间十分钟订正上一张卷子、贴在后墙的月考排名——这些东西一夜之间集体失效，我反而不知道该干什么了。班主任说“再坚持一下，大学就轻松了”，这句话我听了三年。当晚十点，第一次没人管我几点睡，我却失眠了——原来“自由”也是个需要练习的词。

不过失眠归失眠，暑假计划我已经在脑子里排好了。先睡满三天，睡到自然醒，闹钟直接卸载。然后去学车，争取开学前考完科二——听说教练比班主任温柔，我持保留态度。要和同学去看一次海，青岛也好，烟台也好，把高三欠的浪一次补齐。要把书架上落灰的小说全部读完，把收藏夹里吃灰的番追完，还要学会做一道像样的菜端给我妈，让她以后吵架都没话说。对了，还得提前想好“考得怎么样”的标准答案——七大姑八大姨统一发放的那一题，可比数学最后一问难蒙多了。

至于分数，七月自然会来，急也没用。现在我只负责躺平、负责看云，负责把耳朵里三年份的粉笔声和翻页声慢慢倒干净。世界安静下来之后，我终于听见一个很轻的声音，它说：辛苦了。它还说：暑假快乐。接下来的路，按你自己选的方向，慢慢走。
